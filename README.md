# String Manipulation Toolkit (C# / .NET)

## Description
A console-based C# application for performing basic string operations using loops and indexing.

## Features
- Reverse a string
- Check palindrome
- Count vowels

## Technologies Used
- C#
- .NET Console Application

## How to Run
1. Open project in Visual Studio / VS Code
2. Run the application
3. Enter a string when prompted

## Learning Outcome
Improved understanding of string immutability, loops, and character handling in C#.
